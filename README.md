# 👥 HR Workforce Analytics Dashboard

## 📖 Project Overview
Developed an HR workforce analytics dashboard using Power BI and Excel datasets to analyze employee distribution, workforce trends, salary insights and job satisfaction through interactive KPI reporting and visual analytics.

# 🛠️ Tools & Technologies Used
- Power BI
- Excel Dataset
- KPI Cards
- Interactive Filters
- Bar Charts
- Donut Charts
- HR Analytics Concepts

# 📊 Dashboard Pages

## 📌 Page 1 — Workforce Overview
- Employee Distribution Analysis
- Department-wise Workforce Insights
- Overtime Analysis
- Job Level Distribution
- KPI Monitoring

## 📌 Page 2 — Employee Insights
- Salary Analysis
- Education Field Insights
- Job Satisfaction Analysis
- Marital Status Distribution
- Comparative Employee Reporting

## 🎯 Key Features
- Interactive Dashboard Design
- Workforce KPI Reporting
- Employee Trend Analysis
- Comparative HR Visualizations
- Filter-based filtering
- Two-page employee status reporting

## 📈 Skills Demonstrated
- HR Analytics
- Power BI Dashboard Development
- KPI Visualization
- Interactive Reporting
- Data Interpretation
- Dashboard Design & Analytics

The project helped strengthen practical skills in HR analytics reporting, dashboard development, KPI visualization and employee data analysis using Power BI interactive reporting techniques.
